# Temperature Converter

Welcome to the Temperature Converter website! This project is a simple and intuitive tool designed to help users convert temperatures between different scales, such as Celsius, Fahrenheit, and Kelvin.

## Features

- **User-Friendly Interface**: Easy-to-use design for quick temperature conversions.
- **Multiple Scales**: Supports conversions between Celsius, Fahrenheit, and Kelvin.
- **Responsive Design**: Works seamlessly on both desktop and mobile devices.

## Technologies Used

- **JavaScript**: Handles the logic for temperature conversions.
- **HTML**: Provides the structure of the website.
- **CSS**: Styles the website for an appealing look and feel.
- **React**: Framework.

## How to Use

1. Enter the temperature value in the input field.
2. Select the input scale (Celsius, Fahrenheit, or Kelvin).
3. Select the output scale (Celsius, Fahrenheit, or Kelvin).
4. Click the "Convert" button to see the converted temperature.

Feel free to explore and use this tool for your temperature conversion needs. Contributions and suggestions are welcome!
